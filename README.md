# 🎌 Mundo Anime
Uma página web informativa dedicada ao universo dos **animes**, apresentando sua história, principais gêneros, obras famosas, curiosidades, evolução ao longo do tempo e referências visuais.

O projeto foi desenvolvido com **HTML, CSS e JavaScript**, com foco em uma interface organizada, visualmente atrativa e de fácil navegação.


## 📖 Sobre o projeto
O **Mundo Anime** reúne diferentes conteúdos relacionados à cultura dos animes em uma única página.

Entre os assuntos abordados estão:

* História dos animes
* Principais gêneros
* Animes famosos
* Curiosidades da indústria
* Linha do tempo
* Galeria de imagens
* Perguntas frequentes

O projeto possui uma navegação interna através de links que levam diretamente para cada seção da página.


### 🧭 Navegação
Menu de navegação com acesso rápido às principais partes do site:

* História
* Gêneros
* Animes
* Curiosidades
* Linha do tempo
* Galeria
* FAQ


## 🛠️ Tecnologias utilizadas
* **HTML5**
* **CSS3**
* **JavaScript**
* **Bootstrap Icons**

O projeto utiliza o Bootstrap Icons através de CDN para os ícones da interface.


## 📱 Responsividade
O projeto possui a configuração de viewport:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

permitindo que o layout seja preparado para diferentes tamanhos de tela.
O botão de menu também está presente na navegação, utilizando o ícone de menu do Bootstrap Icons.


## 🎯 Objetivo do projeto
O projeto foi desenvolvido como uma página de apresentação sobre o universo dos animes, servindo também como prática de desenvolvimento **Front-End**.

Entre os principais objetivos estão:

* Praticar estruturação semântica com HTML5
* Trabalhar organização de conteúdo
* Criar componentes visuais utilizando CSS
* Trabalhar navegação interna
* Praticar JavaScript para interações da página
* Desenvolver uma página responsiva
* Criar uma interface com aparência moderna
